# Logger

{% hint style="info" %}
**Logger** is an advanced, high-performance Minecraft auditing and analytics plugin designed to watch, record, and log nearly every player activity and server event across Bukkit/Paper/Folia servers and Proxy networks (Velocity, BungeeCord, Waterfall, FlameCord).
{% endhint %}

Packaged as a **Universal 3-in-1 Multi-Platform JAR**, a single binary (`Logger-1.8.4.jar`) runs natively across all backend servers and proxies without separate builds.

We are more than welcome to help you further on our [**Discord Server**](https://discord.gg/MfR5mcpVfX).

---

## Key Highlights in v1.8.4

* **Universal Deployment**: Drop `Logger-1.8.4.jar` on Spigot, Paper, Purpur, Folia, BungeeCord, Waterfall, FlameCord, or Velocity 3.x+.
* **Modern Platform Compatibility**: Supports **Minecraft 1.8.8 through 1.21+** (Paper, Folia, Spigot).
* **Multi-DBMS Native Support**: SQLite, MySQL, MariaDB, and PostgreSQL with HikariCP connection pooling and automated schema migration.
* **Modular Discord Companion Addon**: Companion `LoggerDiscordAddon-1.8.4.jar` with automatic configuration migration and per-player exemption (`logger.exempt.discord`).
* **Official Web Panel**: Real-time web panel featuring live server heartbeat monitoring, real-time analytics, and Discord addon health checks.
* **Security Hardened**: Built with fully patched, modern database drivers (`MariaDB 3.3.5`, `PostgreSQL 42.7.13`, `MySQL Connector/J 8.2.0`).
