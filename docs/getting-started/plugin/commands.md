# Commands

## Proxy Commands

| Command | Permission | Description |
| :--- | :--- | :--- |
| `/loggerproxy` | `loggerproxy.staff` | Displays the proxy plugin help menu. |
| `/loggerproxy reload` | `loggerproxy.staff` \| `loggerproxy.reload` | Hot-reloads proxy configuration files. |
| `/loggerproxy discord` | `loggerproxy.staff` | Displays the official Discord support link. |

---

## Bukkit / Paper / Purpur / Folia Commands

| Command | Permission | Description |
| :--- | :--- | :--- |
| `/logger` | `logger.staff` | Displays the plugin command help menu. |
| `/logger reload` | `logger.staff` \| `logger.reload` | Hot-reloads configs without requiring a server reboot. |
| `/logger toggle spy [commands \| book \| anvil \| sign]` | `logger.staff` | Toggles real-time in-game staff spy features on or off. |
| `/logger discord` | `logger.staff` | Displays the official Discord support link. |
| `/logger dump` | `logger.staff` | Generates a sanitized online pastebin of system information and configs (database passwords and tokens are automatically scrubbed). |
| `/logger playerinventory <player>` | `logger.staff` | Opens an interactive GUI of online players and their historic inventory backups. |
