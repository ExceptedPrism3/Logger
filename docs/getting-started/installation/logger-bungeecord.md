# Logger (BungeeCord / Waterfall / FlameCord)

## Requirements

1. **Java Runtime**: **Java 17 or higher**.
2. **Proxy Platform**: BungeeCord, Waterfall, FlameCord, or compatible fork.

## Installation Steps

1. Download [`Logger-1.8.4.jar`](https://github.com/ExceptedPrism3/Logger/releases).
2. Drop `Logger-1.8.4.jar` directly into your proxy's `plugins/` directory.
3. *(Optional)* If you want Discord notifications for network proxy events, also place `LoggerDiscordAddon-1.8.4.jar` into `plugins/`.
4. Restart your proxy.
5. Configuration files will generate in `plugins/Logger/`.
