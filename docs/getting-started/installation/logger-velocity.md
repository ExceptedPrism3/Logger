# Logger (Velocity)

## Requirements

1. **Java Runtime**: **Java 17 or higher** (**Java 21 recommended**).
2. **Proxy Platform**: Velocity **3.x or higher**.

## Installation Steps

1. Download [`Logger-1.8.4.jar`](https://github.com/ExceptedPrism3/Logger/releases).
2. Drop `Logger-1.8.4.jar` directly into your Velocity proxy's `plugins/` directory.
3. *(Optional)* If you want Discord notifications for proxy events, also place `LoggerDiscordAddon-1.8.4.jar` into the `plugins/` folder.
4. Restart your Velocity proxy.
5. Configuration files will generate in `plugins/logger/`.
