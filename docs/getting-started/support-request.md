# Support Request

Need help setting up Logger or encountering an issue? We're happy to help!

1. **Join our Discord**: [https://discord.gg/MfR5mcpVfX](https://discord.gg/MfR5mcpVfX)
2. **Generate a Diagnostic Dump**:
   * On backend servers (Spigot/Paper/Purpur): Run `/logger dump`.
   * On proxy servers (Velocity/BungeeCord): Run `/loggerproxy dump`.
   * This creates a safe online Pastebin dump of your plugin configurations, active language translations, and recent server logs with tail-truncation protection.
   * *Optional*: You can provide a custom Pastebin API key via the `PASTEBIN_API` environment variable or in a `.env` file in the plugin directory.
3. **Open a Ticket**: Head over to the `#tickets` channel and paste your dump URL and issue description.
